# WordPress.org Plugin Assets

Place the following files here before submitting to WordPress.org:

| File | Size | Notes |
|------|------|-------|
| `banner-1544x500.png` | 1544×500px | Plugin directory banner (high-DPI) |
| `banner-772x250.png` | 772×250px | Plugin directory banner (standard) |
| `icon-256x256.png` | 256×256px | Plugin icon (high-DPI) |
| `icon-128x128.png` | 128×128px | Plugin icon (standard) |

These files are uploaded via the WordPress.org SVN `assets/` directory — they are
NOT served from the plugin ZIP and should NOT be included in the plugin release.
